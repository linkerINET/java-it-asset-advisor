# IT Asset Recommendation Advisor

Java 17+ sample/training project aligned to a **IT Consultant** role.

A Java advisory tool that maps user workload requirements to practical laptop and workstation recommendations.

## Run

```powershell
mkdir out
javac -d out src\Main.java
java -cp out Main
```

## Notes

- Uses only the Java standard library.
- Intended as a small skills demonstration/training project.
- No passwords, tokens or other secrets should be committed.
